# 结构计算模块板V1

工具箱入口：`../index.html`，模块地址：`./`。

当前公开版可使用：截面计算、DXF / 轮廓 JSON 导入、常用截面库、连续梁、荷载、构件验算、项目 JSON 导入导出，以及 HTML 计算书。不满足项沿用红色标注，计算书中的梁图沿用宽幅布局。每位访客的数据保存在自己的浏览器中，不会自动同步给其他人。

“计算示例”载入第二份计算书的完整项目：保留原值1 mm/s²、18格分层壳、28个参考面节点、10个挂点，以及材料、连接、CAD异型立柱、连续梁和原文对照章节。附此前独立求解并验证的结果快照，可直接查看云图和验算；修改有限元输入后原结果失效。示例新建独立项目，保留已有项目；刷新或项目 JSON 往返后可恢复同一份示例快照。

有限元重新求解、DWG 转换和原生 Word/PDF 导出需要在线后台。未接入时，页面说明服务状态并停用相应入口，不会访问访客电脑的本机服务。

`services.json` 中预留 `solverBase`、`reportBase`、`cadBase` 三个 HTTPS 后台地址。后台需实现现有工作台 API，并允许本站的跨域请求；服务器访问控制、计算队列、作业存储及报告下载需要在部署后台时一并配置。不要把本地 Windows 求解程序或工程数据当静态文件上传。

重新生成浏览器代码：

```text
python tools/build-public-workbench.py <工作台项目目录>
```

构建复制前端依赖和用户指定的第二份计算书示例，去掉示例中的本机绝对路径；其他计算书、求解文件和报告不打包。`build-manifest.json` 记录构建文件及指定示例。在线服务配置由部署者独立维护。
