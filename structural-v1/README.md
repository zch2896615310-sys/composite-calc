# 结构计算模块板V1

工具箱入口：`../index.html`，模块地址：`./`。

当前公开版可使用：截面计算、DXF / 轮廓 JSON 导入、常用截面库、连续梁、荷载、构件验算、项目 JSON 导入导出，以及 HTML 计算书。不满足项沿用红色标注，计算书中的梁图沿用宽幅布局。每位访客的数据保存在自己的浏览器中，不会自动同步给其他人。

“计算示例”的示例1载入第二份计算书的完整项目：保留原值1 mm/s²、18格分层壳、28个参考面节点、10个挂点，以及材料、连接、CAD异型立柱、连续梁和原文对照章节。附此前独立求解并验证的结果快照，可直接查看云图和验算；修改有限元输入后原结果失效。示例新建独立项目，保留已有项目；刷新或项目 JSON 往返后可恢复同一份示例快照。


示例2为用户指定的《C塔室内石材蜂窝复合钢板墙面结构计算（6mm）0920.docx》，18个模块。新增可独立添加的挂件荷载与试验需求、压弯构件稳定性、偏心角码强度、锚栓现场拉拔需求；同时采用现有截面和连续梁模块复现角码净截面及横向角钢梁。各示例新建独立项目，不覆盖原项目。

原书的0.24kN/m²自重采用值、1300/1350mm两种分格、手填内力和系数均保留。对照末章列示长细比算术差异、横向角钢梁0.33mm与单轴假定复算0.261653mm等区别；未调参数追平原数值。横梁E/I与荷载位置的恢复依据在模型及导出书中明确记录。理想角钢存在Ixy，单轴梁不直接引用其耦合截面。挂件及锚栓未提供试验值与报告编号时保持待补数据，不判满足。稳定系数为人工输入，未自动查规范表；没有为此Word虚构板有限元模型。

生产站点通过 Netlify Functions 运行 CalculiX 2.23 分层壳与三维实体，修改参数后可直接重新求解。Word 保留可编辑原生公式和表格；PDF 由相同的计算书数据、结果图片和红字标记生成，两种格式分别排版，分页可能不同。计算与导出均使用后台任务，页面轮询进度并领取结果。任务和文件下载有效期24小时，后台每日清理过期任务；项目输入仍可在浏览器保存或导出 JSON 备份。

DWG 在线转换尚未接入；DXF / 轮廓 JSON 仍可直接导入。在线网格上限为2000个分层壳平面单元或5000个实体单元，超限时要求增大网格尺寸，绝不自动更改输入。

`services.json` 中预留 `solverBase`、`reportBase`、`cadBase` 三个 HTTPS 后台地址。本地源码保持无服务模式，Netlify 构建在发布目录中填入生产站点地址。后台运行于云端，不访问访客电脑的本机服务。`tools/sync-cloud-backend.py` 从已验证核心生成跨平台副本，仅替换求解程序路径；构建时以原值1的位移及各层峰值对照验证 Linux 核心，校核失败则停止发布。

重新生成浏览器代码：

```text
python tools/build-public-workbench.py <工作台项目目录>
```

构建复制前端依赖和用户指定的两个计算书示例，去掉示例中的本机绝对路径；其他计算书、求解文件和报告不打包。`build-manifest.json` 记录构建文件及指定示例。在线服务配置由部署者独立维护。

验证命令：`node --test tools/check-public-workbench.mjs tools/check-word0920.mjs`。包括两个示例依赖和ID重建、试验待补/失败状态、荷载联动、稳定性算术及失效分母拒绝、角码截面独立公式、横向梁力及力矩平衡、原值列保留和导出红字标记。
